发布：1.0.0

模型整理插件进入 1.0.0。相对 0.0.3 的主要变化是新增模型自定义排序，并把四份
README 补到与实际功能一致。

功能：

- 每个模型左侧一对上下箭头，调整其在所属渠道内的先后；渠道头提供「恢复该
  渠道默认排序」
- 排序显式保存到插件自己的 order 字段（按渠道存一组模型 id），重启后仍然生效
- 排序只决定排列，不决定可见性：隐藏的模型保留它在顺序里的位置，重新显示时
  回到原处
- 渠道以后新增的模型排在你已排列的那些之后
- 搜索筛选时箭头交换的是当前可见的相邻两项，被筛掉的行保持各自相对位置

修复：

- 装载目录后补调 syncSavedOrder()。此前该方法只有定义、从未被调用，保存的顺序
  读不回来，整个排序功能实际不可用

文档：

- 四份 README 新增「自定义排序」一节，并更新界面示意图（箭头、恢复默认排序
  按钮）与测试套件数量说明
- 语言栏四语互链校验通过

质量：

- npm test 扩到九套、186 项断言，全部通过
- check:packaging 与 README 语言栏校验均通过
