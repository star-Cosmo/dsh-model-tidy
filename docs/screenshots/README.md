# 截图

README 引用的 `main.png` 与 `main01.png` 是「模型整理」设置页的实际截图，市场按 `screenshots.json` 的顺序展示这两张。

`main.png` 应包含：

- 顶部的说明文字与右上角的 Star 入口
- 搜索框、恢复渠道默认顺序、全部显示 / 全部隐藏、可见计数
- 渠道卡片（卡头为排序箭头 + 渠道名 + 可见/总数 + 渠道备注/恢复排序/隐藏本渠道/显示本渠道）
- 每行的排序箭头、设置备注、开关，最好含已隐藏的行（划线样式）

`main01.png` 应包含：

- 第二张视角：含返回顶部的圆形 `↑` 按钮（页面内容区右下角）
- 已备注模型或倍率后缀（如 `DeepSeek-V4.1-Flash · x0.12`）

替换本目录下的图片即可，无需改动 README。
